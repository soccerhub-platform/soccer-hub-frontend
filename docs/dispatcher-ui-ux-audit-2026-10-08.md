- Frontend: http://127.0.0.1:3001, backend: http://127.0.0.1:8081.
- Dev PostgreSQL: `soccer_hub`, контейнер `soccer-hub-db-1`, порт 5490.

- Сохранены клуб `QA Dispatcher Club`, филиалы `QA Центральный` и `QA Северный`, администратор `codex.admin@qa.soccerhub.test` и 23 тестовые заявки. Основной QA администратор назначен на Центральный филиал.

## Исправленные проблемы

| Проблема | Изменение |
| --- | --- |
| Создание лида отправляло устаревшие `parentName/children/age`; сервер возвращал Validation failed | Текущий контракт `leadType/primaryContact/participants/birthDate`, детские и взрослые заявки |
| Список терял все заявки после первой страницы API | Серверная пагинация по 20, общее количество, следующая/предыдущая страница |
| У самодельного окна лида отсутствовал стандартный диалог, содержимое и футер выходили за экран | Общий ModalShell с правой панелью, управлением фокусом и прокруткой тела |
| Фиксированный sidebar мешал работе на телефоне | Мобильное меню; сворачиваемый sidebar на desktop |
| Старые градиенты и дублирующая шапка не совпадали с остальным проектом | Общие PageHeader/SectionCard, семантические цвета, плоское рабочее пространство |
| Dashboard без филиалов показывал бесполезный пустой selector | Пустое состояние с переходом к созданию клуба и филиала |
| Выбор филиала dashboard и лидов расходился | Общий query и сохраняемый выбор; проверка, что филиал ещё доступен |
| Slug клуба переставал обновляться после первого символа | Генерация по полному названию до ручного изменения; сброс черновика при открытии |
| API списка клубов не возвращало сохранённый email | Email добавлен в backend projection и DTO |
| Повторное сохранение форм могло создавать дубликаты | Pending guards, отключение кнопок сохранения и закрытия во время запроса |
| Повторное назначение уже назначенного филиала | Форма предлагает только доступные неназначенные филиалы |
| Открепление показывало успех, но после reload связь оставалась | Удаление из управляемой коллекции родителя перед repository.delete: JPA cascade больше не восстанавливает связь |
| Карточка администратора могла оставаться со старым набором филиалов после refresh | Синхронизация выбранного администратора с обновлённым списком |
| После открепления последнего филиала редактирование и смена статуса возвращали 404 | Создатель администратора проходит проверку прав независимо от назначений |
| Переключатели статуса имели ошибочные доступные названия из-за вложения в label | Field и ToggleGroup с отдельными именами |
| Старые прямые `/dispatcher/clients` и `/dispatcher/trial-trainings` вызывали несуществующие API и показывали ошибку вместе с пустым списком | Redirect на лиды; неизвестные dispatcher маршруты на dashboard |

## Проверка в браузере

- Вход QA dispatcher; навигация dashboard, лиды, клубы/филиалы, администраторы, профиль.
- Создание QA клуба и Центрального филиала; создание Северного филиала обновлённой формой. Email клуба отображается.
- Автокод `QA Full Name → qa-full-name`; закрытие и повторное открытие очищает черновик.
- Создание администратора, редактирование телефона, отключение/включение, назначение второго филиала.
- Открепление Северного филиала: после полной перезагрузки он отсутствует в карточке.
- Создание детской и взрослой заявки обновлённой формой. Просмотр контакта, email, участника, возраста, комментария; поиск взрослой заявки.
- 23 заявки: страница 1 содержит 20, страница 2 — 3 (`21–23 из 23`), кнопка Далее отключена на последней странице.
- Фильтр «Отказ» даёт 0 заявок; доступен сброс фильтров.
- Выбор Северного филиала в лидах сохраняется на dashboard; пустая аналитика этого филиала отображается без ошибки.
- Профиль: сохранённые телефон, специализация и настройки уведомлений видны после reload.
- Viewport 390×844: мобильное меню содержит все разделы, форма лида прокручивается при закреплённом футере; обязательные поля показывают ошибки. Document scrollWidth=clientWidth=390.
- Оба старых маршрута перенаправляются на лиды.

## API и автоматические проверки

- Отдельный временный QA admin: reset-password → успешный login с новым временным паролем; открепление последнего филиала → редактирование, disable, enable, delete.
- Временный QA club/branch: create, read, сохранение email, delete; исчезновение проверено повторным GET.
- Пароль основной учётной записи dispatcher не менялся. Ввод/смена пароля в браузере не выполнялись; reset проверен через локальный API.
- Frontend: typecheck, lint, build и 96 unit tests проходят.
- Backend: DispatcherClubServiceTest, AdminBranchServiceTest, DispatcherAdminServiceTest проходят (3 regression tests).

Удаление через браузер проверялось до окна подтверждения; фактическое удаление временных fixtures выполнено через API. Это ручной browser audit и направленные regression tests, не исчерпывающий автоматический E2E всех комбинаций. Изменения других ролей и существующие правки рабочей копии в этот отчёт не включены.
